### 阶段写集、证据与风险规则

- 每阶段只有获准模块可写；生产 `user_install.plan_install`/`upgrade._plan` 的 darwin 拒绝、agents.json 的未知平台拒绝在整体准入前保留。上述写集是未来计划，非本轮已修改清单。
- 优先复用官方 SDK 注册 host route 机器传输，不让模型手抄大段 bytes，不读/导出配对凭据，不开 HTTP listener，不改 daemon/relay/provider/全局 Git。所有同步先源清单+逐文件 SHA/size，未匹配不得运行。
- 每轮原生执行使用新唯一子根；保存 argv、cwd、限定环境、stdout/stderr、exit、起止、版本/文件系统、快照与 request/terminal ID。迟到请求归属不明则该轮边界受限，不能用空列表证明从未执行。
- 原始证据留 Windows evidence 与 Mac私有暂存；提交库内的只有脱敏结论/指纹索引，不放 SID、DACL 正文、凭据、配对链接。原始 /tmp 不是持久保管承诺；若消失需报告证据缺失，不由摘要重造。
- joined.b64 继续登记指纹不符/归属未知；不删除、不扩大定位，它不无限阻断独立根开发，但隔离 partial 不能悄悄转绿。
