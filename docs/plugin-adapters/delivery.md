## 已实现

- 唯一 Python 业务真源仍为 `scripts/agm_core`。生成器从干净固定 S 生成 Paseo 自包含载荷与摘要，R 保留原 clean/full-pin、同版与 conversion 门禁。普通根入口和插件使用相同核心身份；持久 export 独立预览批准，导出不等于机器安装完成。
- Paseo Command Center、一次性确认界面和 typed RPC；完整计划、稳定摘要与独立一次性 confirmationToken 绑定 host/HOME/argv/内核。enable/remove 显式只读预览，记忆政策保留/启用/禁用三态由原 CLI 执行；rebuild 未代填独立批准。
- 当前包来源经原发行解析器验证，不用任意历史库存；运行取消保留原 journal，恢复只使用匹配原来源与工具 hash 的材料。宿主状态仅辅助记录，不替代产品台账。
- 安全进程组取消、下载 hash/容量/背压/不覆盖发布、解包路径/容量/执行位、独占证据和祖先软链接拒绝。公共 Node 真源通过生成副本放入插件目录，不依赖安装后的父目录。
- CK 固定 URL/pin 的来源获取与原安装器安装分别批准；RPC 不接受用户传入来源路径，不自动建项目记录库，不模拟自动保存。上游和既有入口所有权保持不变。
- [发行工具说明](../../tools/plugin-release/README.md) 给出 S→外部生成→仅生成物放回→获授权的 R→核验流程。[check.py](../../tools/plugin-release/check.py) 是可供 CI 调用的只读入口；未配置远程 CI 服务或执行正式发布。
