# 公共用户记忆与融合 PRD

## 记忆归属与常驻内容

保存用户记忆时，适用于所有 Agent 的规则、偏好和长期事实写入公共 memories 对应文件；仅适用于某 Agent 的内容保留于其用户记忆。项目规则和项目经历留在项目。归属不明先澄清，不自动删除或共享专属内容。

MEMORY.md 是精简索引，保留读取、保存归属、自动项目接入及按需操作入口。新增主题加链接；菜单、操作命令和详细流程放 Skill，不复制到公共记忆，不在全新安装中创建重复的“使用约定”手册。正文完整保留，不为压缩索引改写正文。

各家用户入口只留必要公共读取指针；Claude/WorkBuddy 可保留实际使用时补项目入口的短触发。不要重复说明 AI 已知常识、作者身份或环境变量保护细节。

## 读取、分组与选择

完整读取本次实际参与者后，Agent 结合语境与作用域提出方案。读失败/截断为未知，不能当空文件；分母是本次实际参与者，不固定六家。

- 默认共享：至少两家参与、所有参与者有同内容且语境/作用域相同。
- 由你选择是否共享：部分覆盖项及可共享的单家项，默认不选；标来源和单家默认不共享。
- 专属、受保护协议和不明确项不自动迁移。同标题不等于同内容，作用域不同不去重。

两块全局连续编号，查看/选择/执行沿用稳定编号；空块写“暂无”。Agent 摘要建立在完整阅读上；纯 CLI 只能把忠实截取标为原文摘录，不伪装语义摘要。

`按默认方案` 只选默认项；`不共享 2` 排除对应默认项；待选编号在默认方案上追加；支持组合输入。`查看 3` 仅展示完整原文与来源，零写、不选择。无效或含糊选择只澄清必要范围。

## 选择即执行

用户明确选择即授权执行该方案，不要求第二次“确认执行”。方案须让用户理解迁入公共、核验入口后删对应重复片段、未选和专属保留及备份安排；提供完整原文查看入口。

执行时仍生成可审计完整修改清单，含参与者、编号、原文、作用域、精确字节范围、公共目标、源删除片段、入口和恢复位置。内部批准记录绑定真实用户选择及实际计划，不能虚构用户见过另一份清单。查看不是批准。执行前出现实质变化，停止并说明差异，不能沿用旧选择静默扩大操作。

## 写入、去重与清理

先写公共全文，核验公共与读取入口，再删精确来源片段。仅正确分组、作用域及原文字节满足去重条件才存一份；保留每处来源与次数，支持后续逐处归还。同名章节、重复出现及不同语境单独处理。

已有有效公共指针时复用，不另加第二个 `memory-index` 指针。对历史重复的产品受管指针，确认所有权与目标后只保留一个有效入口，兼顾台账、恢复及重复安装；不得按任意相似文本粗删。

迁移后“用户规则”章节确实为空，移除空标题和多余空行；仍有未选或专属正文就保留。代码块内示例、其他作用域同名标题不误删。空壳清理与正文迁移属于同一可恢复修改计划。

## 验收标准

覆盖全覆盖/部分/单家/未知/同标题不同语境、查看零写、选择后直接执行、第二次增量共享、公共新增编辑、私文漂移拒绝、同作用域去重与来源次数、指针复用、空章节清理、崩溃后恢复。失败不得丢失正文、伪报完成或放宽漂移保护。

## 参与与边界判定

缺失或空来源记为无内容，读取失败/截断记为未知；未知不能当空值或据此推定全覆盖。N≥2 且全部参与者同语境同内容才默认共享；部分覆盖与 N=1 保留待选。近似、冲突或格式差异不盲并，不丢任一原文变体。只改变本次选定范围，不能顺带整理其他项目、用户私文或项目经历。

界面类别统一为“用户记忆、项目记忆、项目经历”，操作动词用“共享”；技术文件名可以保留。不用测试数、代理数量或配置声明代替用户可用性；正常第二次共享、公共后续编辑和退出是验收的一部分。

公共正文按来源自然顺序写入；相邻同语境条目复用工具生成的包装标题，不逐条重复。仅处理合成包装，不改原文标题、代码块或不同作用域；增量保留已有公共前缀，并核对每处迁移偏移和来源次数。
